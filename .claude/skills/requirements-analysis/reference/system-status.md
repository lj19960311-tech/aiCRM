# 系统现状模板

## 概述

描述当前 AI 销售秘书系统的整体情况，包括功能页面、模块划分以及现状。

---

## 一、功能模块清单

| 序号 | 模块 | 说明 | 状态 |
|------|------|------|------|
| 1 | 对话首页 | 用户发起对话的主界面 | 已实现 |
| 2 | 专家技能 | 展示可用的 AI 专家技能 | 已实现 |
| 3 | 我的文件 | 管理 AI 生成的报告、方案等文件 | 已实现 |
| 4 | 客户笔记 | 记录和管理客户关键信息 | 已实现 |
| 5 | 金牌陪练 | 销售话术对练，模拟客户对话 | 已实现 |
| 6 | 智能讲解 | AI 驱动的产品/平台介绍讲解 | 已实现 |

## 二、系统现状详述

### 2.1 AI 销售秘书（PC 端 Demo）

**技术栈**：React 19 + React Router 7 + Ant Design 6 + Vite 8

**布局结构**：左侧边栏（248px）+ 右侧内容区，无 TabNav

**主题配色**：
- 主色调：紫色 `#7b6cf0` / `#6d5ef0`
- 陪练专属：橙色 `#b4552d`
- 背景色：`#f4f4f6`（页面），`#fbfbfc`（侧边栏）

#### 模块列表

| 模块名称 | 页面/功能 | 路由 | 现状描述 |
|----------|-----------|------|----------|
| 对话首页 | 新建对话 | `/home` | 欢迎区 + 能力卡片 + 底部输入框，使用模拟对话数据 |
| 专家技能 | 技能列表 | `/skills` | 按类别分组展示 AI 专家技能卡片 |
| 我的文件 | 文件管理 | `/outputs` | 文件卡片网格，支持收藏和筛选 |
| 客户笔记 | 笔记列表 | `/memory` | 客户信息卡片，含标签、联系人、摘要 |
| 金牌陪练 | 销售对练 | `/coach` | 场景选择 + 对话练习 + 实时评分反馈，橙色专属配色 |
| 智能讲解 | 平台介绍 | `/present` | 幻灯片式内容展示，支持播放控制 |

#### 侧边栏功能

| 功能 | 描述 |
|------|------|
| 搜索框 | 支持搜索功能、文件、对话 |
| 新建对话 | 快捷跳转到对话首页 |
| 导航列表 | 专家技能、我的文件、客户笔记 |
| 智能体分类 | 金牌陪练（智能体）、智能讲解（内测预览） |
| 历史对话 | 可折叠的对话历史列表 |
