# 代码风格约定

## 组件命名

- PascalCase，如 `OrderList.jsx`
- 一个页面一个目录，目录下可包含子组件

## 文件组织

```
pages/
└── [模块名]/
    ├── index.jsx      # 页面入口
    └── components/    # 页面私有组件（按需）
```

## 样式方案

- 优先保持当前项目已经采用的样式方式，不为局部修改引入新的样式体系
- AI 销售秘书默认使用 antd 组件自带样式、inline style 和已有全局 CSS，不新增 CSS Modules
- 修改全局样式时控制作用范围，避免污染无关页面

## 注释规范

- 只在复杂业务逻辑处添加注释
- 不做冗余注释

## Hooks 使用

| Hook | 用途 |
|------|------|
| `useState` | 管理组件内部状态 |
| `useEffect` | 处理副作用 |
| `useContext` | 仅在确有跨组件共享状态时使用 |
| `useMemo` / `useCallback` | 仅在性能确实需要时使用 |

## antd 组件使用

- 直接使用，不做二次封装（除非有明确的复用需求）
- 默认主色使用紫色 `#7b6cf0` / `#6d5ef0`
- 金牌陪练页面使用橙色 `#b4552d`
