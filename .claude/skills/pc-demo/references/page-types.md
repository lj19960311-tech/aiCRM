# 页面类型规范

AI 销售秘书是**对话式 AI 助手**，页面类型不同于传统 CRUD 后台。以下是已实现的实际页面类型：

---

## 一、对话首页（Home）

对话式 AI 的主界面，用户在此发起和进行对话。

```
┌─────────────────────────────────────────┐
│  欢迎区域                                │
│  "你好，我是 AI 销售秘书"                │
│  简短介绍 + 能力提示                      │
├─────────────────────────────────────────┤
│  能力卡片展示区                           │
│  ┌──────┐ ┌──────┐ ┌──────┐            │
│  │客户  │ │话术  │ │方案  │            │
│  │分析  │ │优化  │ │撰写  │            │
│  └──────┘ └──────┘ └──────┘            │
├─────────────────────────────────────────┤
│  专家技能卡片（可选推荐）                 │
├─────────────────────────────────────────┤
│  底部输入框                              │
│  [输入您的问题...]    [发送按钮]          │
└─────────────────────────────────────────┘
```

### 核心元素

- **欢迎文字**：简洁问候 + 身份介绍
- **能力卡片**：展示核心能力，卡片支持 hover 效果（阴影 + translateY）
- **输入框**：固定在页面底部，支持多行输入
- **对话历史**：通过侧边栏管理，不在内容区展示

## 二、专家技能页（Skills）

展示可用的 AI 专家技能，按类别分组。

```
┌─────────────────────────────────────────┐
│  页面标题：专家技能                       │
├─────────────────────────────────────────┤
│  技能分组                                 │
│  📊 分析类                               │
│  ┌──────────────┐ ┌──────────────┐      │
│  │ 客户分析专家  │ │ 市场趋势专家  │      │
│  │ 描述文字...   │ │ 描述文字...   │      │
│  │ 使用次数      │ │ 使用次数      │      │
│  └──────────────┘ └──────────────┘      │
│                                         │
│  💬 沟通类                               │
│  ┌──────────────┐ ┌──────────────┐      │
│  │ 话术优化专家  │ │ 异议处理专家  │      │
│  └──────────────┘ └──────────────┘      │
└─────────────────────────────────────────┘
```

### 核心元素

- 按类别分组（分析、沟通、文档等）
- 每张卡片展示：图标、名称、描述、使用次数
- 卡片网格布局，响应式排列

---

## 三、文件管理页（Outputs）

管理 AI 生成的文件（报告、方案、分析文档等）。

```
┌─────────────────────────────────────────┐
│  页面标题：我的文件      [搜索] [筛选]    │
├─────────────────────────────────────────┤
│  文件类型筛选：全部 | PDF | Word | Excel │
├─────────────────────────────────────────┤
│  文件卡片网格                            │
│  ┌──────┐ ┌──────┐ ┌──────┐            │
│  │ 📄   │ │ 📄   │ │ 📄   │            │
│  │报告名│ │方案名│ │分析名│            │
│  │大小  │ │大小  │ │大小  │            │
│  │日期  │ │日期  │ │日期  │            │
│  └──────┘ └──────┘ └──────┘            │
│                                         │
│  ⭐ 收藏文件置顶展示                      │
└─────────────────────────────────────────┘
```

### 核心元素

- 文件卡片展示（图标、文件名、大小、日期）
- 支持收藏/取消收藏
- 支持按文件类型筛选

---

## 四、客户笔记页（Memory）

记录和查看客户相关信息，类似 CRM 的客户档案。

```
┌─────────────────────────────────────────┐
│  页面标题：客户笔记      [搜索] [新建]    │
├─────────────────────────────────────────┤
│  客户笔记列表                            │
│  ┌─────────────────────────────────┐    │
│  │ 农夫山泉                  2026-08-25 │
│  │ 联系人：张经理 | 行业：食品饮料   │    │
│  │ 标签：[重点客户] [饮用水]         │    │
│  │ 摘要：对大包装水有需求...         │    │
│  └─────────────────────────────────┘    │
│  ┌─────────────────────────────────┐    │
│  │ 娃哈哈集团                2026-08-24 │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

### 核心元素

- 客户卡片：名称、联系人、行业、标签、笔记摘要
- 支持搜索筛选
- 支持新建笔记

## 五、金牌陪练页（Coach）

销售话术对练场景，模拟客户与销售员的对话练习。

```
┌─────────────────────────────────────────┐
│  金牌陪练                                │
├─────────────────────────────────────────┤
│  场景选择区                              │
│  ┌────────────┐ ┌────────────┐          │
│  │ 客户异议   │ │ 新品推介   │          │
│  │ 处理       │ │            │          │
│  └────────────┘ └────────────┘          │
├─────────────────────────────────────────┤
│  对话区（选中场景后进入对练）             │
│  ┌─────────────────────────────────┐    │
│  │ 🧑‍💼 客户：你们的价格比竞品高了   │    │
│  │    15%...                       │    │
│  ├─────────────────────────────────┤    │
│  │ 👤 我：感谢反馈，我们的定价...   │    │
│  │    📝 评分：75                  │    │
│  │    💡 建议：先肯定客户的价格...   │    │
│  └─────────────────────────────────┘    │
│                                         │
│  [输入回复...]          [发送]           │
└─────────────────────────────────────────┘
```

### 核心元素

- **场景选择**：预设多个对练场景（异议处理、新品推介等）
- **对话区**：模拟客户与销售员的多轮对话
- **实时评分**：对每轮回复给出评分
- **即时反馈**：给出改进建议
- **专属配色**：橙色主题（`#b4552d`），区别于紫色主色

- 紫色主题控制按钮

## 通用组件规范

### 卡片样式

```jsx
{
  background: '#fff',
  borderRadius: 14,
  padding: '16px 18px',
  border: '1px solid #ececef',
  transition: 'all .15s',
  // hover 效果
  ':hover': {
    boxShadow: '0 2px 8px rgba(109, 94, 240, 0.08)',
    transform: 'translateY(-2px)',
  }
}
```

### 按钮样式

- 主操作（新建对话）：`background: '#1c1c22', color: '#fff'`
- 紫色操作：`background: '#6d5ef0', color: '#fff'`
- 圆角：20px（小按钮），10px（大按钮）
